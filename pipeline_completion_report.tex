\vspace{1em}

\begin{tcolorbox}[infoBox={Executive Summary}]
This report documents the completion of the psychotherapy dataset curation pipeline for the Context-Aware AI Psychotherapy system. The pipeline consists of five modular scripts that ingest, clean, transcribe, annotate, and format therapeutic conversation data from six open-source datasets plus three pre-trained models. All modules pass import and self-tests on Apple Silicon M4 (MPS backend). PII scrubbing is integrated end-to-end using Microsoft Presidio with a custom clinical medical-ID recognizer.
\end{tcolorbox}

\subsection{Data Flow Diagram}

\begin{enumerate}[label=$\rightarrow$\ \arabic*., leftmargin=*, itemsep=0.5em]
\item \textbf{Raw Inputs} --- Open-source datasets (HuggingFace Hub) and local TransferNow zip archive containing three pre-trained models
\item \textbf{Module 1 (PII Scrubber)} --- Presidio analyzer + anonymizer with custom medical-ID recognizer; applied to all text at ingestion
\item \textbf{Module 2 (Transcriber)} --- faster-whisper with code-switching support; converts mock clinical audio to text
\item \textbf{Module 3 (Dataset Builder)} --- Aggregates 6 datasets, applies PII scrubbing post-merge, filters to 500--2{,}000 rows
\item \textbf{Module 4 (Annotator)} --- Loads 3 zipped models for emotion (30 labels) + behaviour intent (8 labels) annotation; exports ChatML JSONL
\item \textbf{Module 5 (Runner)} --- Orchestrates end-to-end pipeline with CLI arguments
\end{enumerate}

\textcolor{indigo}{\textsf{S}}\ \textbf{File}: \texttt{pii_scrubber.py} (607 lines)

\begin{tcolorbox}[infoBox={Technology Stack}]
Microsoft Presidio v2.2.364 (presidio-analyzer + presidio-anonymizer), spaCy v3.8.16 with \texttt{en\_core\_web\_sm}, custom regex recognizers for clinical PII entities.
\end{tcolorbox}

\paragraph{Key Fixes Applied}

Three critical API-compatibility bugs were identified and fixed during development:

\begin{enumerate}[label=\textcolor{teal}{\textsf{!}}\ \arabic*., leftmargin=*]
\item \textbf{Pattern import}: The non-existent import path \texttt{presidio\_analyzer.recognizer\_pattern} was replaced with the correct \texttt{from presidio\_analyzer import Pattern, PatternRecognizer, RecognizerResult}
\item \textbf{OperatorConfig API}: Parameter names were updated from \texttt{operator=} / \texttt{replace\_params=} to \texttt{operator\_name=} / \texttt{params=} (Presidio 2.2.364 signature)
\item \textbf{NlpEngineProvider}: The old constructor with \texttt{nlp\_engine\_name} and dict keys \texttt{lang}/\texttt{model} was replaced with direct \texttt{SpacyNlpEngine(models=[{"lang\_code": "en", "model\_name": "en\_core\_web\_sm"}])}
\end{enumerate}

\paragraph{Overlap Resolution}

A priority-based overlap resolver ensures custom clinical regex entities (Aadhaar, medical IDs) take precedence over Presidio NER when they overlap at the same position. The resolver checks for same-type overlap only, preventing legitimate non-PII entities from being masked.

\subsection{Module 2: Multilingual Audio-to-Text}
\textcolor{teal}{\textsf{M}}\ \textbf{File}: \texttt{transcriber.py}

\begin{tcolorbox}[infoBox={Technology Stack}]
faster-whisper (optimized Whisper inference), VAD-based audio chunking, bilingual/trilingual code-switching support, automatic language detection.
\end{tcolorbox}

\paragraph{Key Features}
\begin{itemize}[label=\textcolor{teal}{$\checkmark$}, leftmargin=*]
\item Code-switching support: handles mixed-language audio (e.g., English--Kannada, English--Hindi)
\item Language detection via Whisper's built-in language identification
\item VAD-based segmentation for long clinical sessions
\item MPS/CPU fallback for Apple Silicon M4
\item Error handling for missing/corrupt audio files (returns empty result, logs warning)
\end{itemize}

\paragraph{Quality Filtering}

The \texttt{filter\_and\_sample} function applies these criteria:
\begin{enumerate}[label=\textcolor{orange}{\textsf{F}}\ \arabic*., leftmargin=*]
\item Remove rows with missing/null text
\item Remove rows shorter than 5 characters
\item Remove duplicate utterances (exact text match within source)
\item Filter to conversations with minimum 2 turns (patient + therapist exchange)
\item Sample to target conversation count (default: 1{,}500, range: 500--2{,}000)
\end{enumerate}

\section{Presidio API Compatibility Notes}

This section documents resolved API mismatches between expected and installed Presidio versions.

\begin{tcolorbox}[colback=lightgray!30, colframe=indigodark, title=API Migration Notes, fonttitle=\sffamily\bfseries]
\begin{description}[leftmargin=2.5cm, labelwidth=2cm]
\item[Pattern import] \texttt{presidio\_analyzer.recognizer\_pattern.Pattern} ---DNE. Use \texttt{presidio\_analyzer.Pattern}
\item[OperatorConfig] \texttt{operator="replace"} ---DNE. Use \texttt{operator\_name="replace"}
\item[OperatorConfig params] \texttt{replace\_params=\{...\}} ---DNE. Use \texttt{params=\{...\}}
\item[NlpEngineProvider] Old API with \texttt{nlp\_engine\_name} kwarg ---DNE. Instantiate \texttt{SpacyNlpEngine} directly
\item[SpacyNlpEngine models] \texttt{"lang": ..., "model": ...} ---DNE. Use \texttt{"lang\_code": ..., "model\_name": ...}
\end{description}
\end{tcolorbox}

\section{Output File Schemas}

\begin{tcolorbox}[colback=lightgray!30, colframe=teal, title=Final Output Schema, fonttitle=\sffamily\bfseries]
\begin{description}[style=nextline]
\item[curated\_psychotherapy\_dataset.jsonl] One JSON object per line. Each object:
\begin{itemize}
\item \texttt{messages}: list of ChatML-format messages (\texttt{system}, \texttt{user}, \texttt{assistant})
\item \texttt{metadata}: source, conversation\_id, num\_turns
\item Per-message \texttt{metadata} includes \texttt{emotion}, \texttt{behaviour}, \texttt{source}
\end{itemize}
\item[curated\_dataset.csv] Filtered DataFrame with columns: \texttt{conversation\_id}, \texttt{turn\_id}, \texttt{speaker}, \texttt{text}, \texttt{emotion}, \texttt{source}, \texttt{metadata}
\item[curated\_dataset\_merged.csv] Full merged dataset before filtering (all sources, all rows)
\end{description}
\end{tcolorbox}
